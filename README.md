# Jamal's Archive Website For Lethal Ape, that wasn't accepted. — Open Source

*A free, open-source version of Jamal's Archive Website originally created by QD5L.

This project was created as an alternative version that was not used by the original requester. It is now being provided as an open-source project for anyone who wants to use, customize, and rebrand it.

Note: Please read the setup instructions below before using the website.

# 📦 Installation
1. Download the Project

Download the ZIP file containing the entire project.

After downloading it, extract the ZIP file to a location of your choice.

# 2. Open the Project

Open the extracted folder using either:

Visual Studio Code
Visual Studio / your preferred code editor

Then open the project files.

# 🎨 Customizing the Website

Open:

index.html


Search through the file for references to Lethal Ape and replace them with your own branding.

You can customize things such as:

Website name
Logos
Text
Images
Colors
Links
Social media information
Other branding elements
# ⚠️ Developer Credit

# 📁 Assets Folder

Create an assets folder in the project if one does not already exist.

Your folder structure should look similar to this:

assets/
├── la-shot-1
├── la-shot-2
├── la-shot-3
├── la-shot-4
├── la-shot-5
├── la-shot-6
├── la-shot-7
├── la-shot-8.webp
└── shots/


The shots folder should be located inside the assets folder.

assets/shots/

# 🖼️ Images

The website uses screenshots/images for various sections.

Make sure the required images are placed in the correct folders and that their filenames match what is referenced by the website.

la-shot-1-8 should be a .webp image. All of them

If you change the filenames, remember to update the corresponding references in the HTML/CSS/JavaScript files.
